교환 가능 — 동일 조건 충족

상품·옵션·금액·과세 유형이 모두 일치합니다. 교환 전 상품에 적용된 할인이 교환 후 상품에 그대로 승계되며, 기존 스냅샷 기준의 잔여 수량·잔여 환불 가능액을 유지합니다. 별도의 세금 재계산은 발생하지 않습니다.

화면 설명

  1. 1
    교환 대상 상품 (스냅샷)

    교환을 신청할 원 상품의 상품명·옵션·과세구분·수량·상품금액·할인 배분액을 주문 완료 시점 스냅샷 기준으로 표시합니다. 수정할 수 없습니다.

    정책서 3.1절 · 7장
  2. 2
    교환 후 상품 선택
    • 운영자가 교환할 상품·옵션을 선택하면 상품금액·과세구분이 자동으로 채워짐

    이 값은 아래 "허용 조건 검증"에서 원 상품과 비교하는 기준이 됩니다.

  3. 3
    허용 조건 검증 교환 허용 조건 :
    1. 상품 동일
    2. 옵션 동일
    3. 금액 동일
    4. 과세 유형 동일

    네 조건을 모두 충족해야 "일치"로 표시되며, 하나라도 다르면 해당 항목이 "불일치"(빨간색)로 표시됩니다.

    정책서 7장

  4. 4
    결과 안내 박스
    1. 교환 가능 (녹색)4개 조건 모두 일치 시 노출. 할인 필수 승계, 재계산 없음, 기존 잔여 수량·환불 가능액 유지 안내
    2. 교환 불가 (빨간색)조건 중 하나라도 불일치 시 노출. 차액 정산·과세 유형 변경 등이 필요한 교환은 후속 검토 대상이며 지원 여부·시점 미확정이라는 제한 안내
    정책서 7장

    2. 하나라도 불일치하면 버튼 비활성화(회색)로 신청 자체를 차단
