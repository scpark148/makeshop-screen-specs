화면 설명

  1. 1
    환불금액 계산 (환불 대상 상품)
    • 상품 목록에 과세구분 항목을 신규로 추가
    1. 과세구분 배지추가된 과세구분 항목에 상품별 과세/면세/영세 값을 배지로 표시

    모든 금액은 주문 완료 시점에 저장된 스냅샷 기준이며 현재 조건으로 재계산하지 않습니다. 할인 배분액도 항상 주문 당시 저장값을 사용합니다.

    정책서 2장 · 3.1절
    • 1-1
      상품 금액 상세보기 (행별 토글)
      • 버튼 클릭 시 바로 아래에 해당 상품의 저장 금액 내역이 펼쳐짐
      사용법 : 클릭 → 펼침(텍스트 "상세 접기"로 변경) → 재클릭 시 접힘
      1. 펼쳤을 때 노출상품별 주문금액 / 상품 직접 할인 / 주문·쿠폰 할인 배분 / 적립금·예치금 배분 / 상품별 환불 예상액(최종값)

      모두 스냅샷 저장값이며 수정할 수 없습니다. 공통 클레임 화면 정책: 복합과세 주문에서는 메이크샵 할인금액 재적용 체크박스를 노출하지 않습니다. 설정이 켜져 있어도 재적용하지 않으며, 주문 당시 저장된 상품별 할인 배분액을 사용합니다.

  2. 2
    환불 예상액 · 상세보기

    팝업에 노출된 전체 상품의 환불 예상액 합계이며, 토글을 눌러 과세/면세/영세별 합계를 확인할 수 있습니다.

    • 2-1
      환불 예상액 상세보기 (토글)
      • 버튼 클릭 시 환불 예상액 아래에 세금유형별 합계 상세가 펼쳐짐
      사용법 : 클릭 → 펼침(텍스트 "환불 예상액 상세접기"로 변경) → 재클릭 시 접힘 (기본값 : 접힘)
      1. 펼쳤을 때 노출과세 상품 환불액 / 면세 상품 환불액 / 영세 상품 환불액 / 전체 상품 환불 예상액(합계)

      환불 예상액은 상품별 환불액을 합산한 금액이며, 이 상세보기는 그 합산값을 세금유형 기준으로 재집계해 보여줍니다.

  3. 3
    배송비 환불액 (최초배송비)
    • 기준 : 주문 당시 저장된 전액 과세 배송비 금액 (환불 예상액에서 차감)
    1. 전액 과세과세 배송비 단일 금액과 환불 포함 체크박스 1줄을 노출 (금액 수정 불가)
    노출 기준 :
    1. 주문 전체 상품 구성과 무관하게 전액 과세 배송비 단일 행을 노출

    취소 대상에 과세 카드 환불 가능액이 있으면 배송비 차감을 포함한다. 면세 상품 단독 취소는 배송비 차감을 적용하지 않고 0원으로 표시한다.

    정책서 8.1~8.2절
  4. 4
    그 외 환불 정보 항목
    • 반송비 / 재발송 배송비(각 비용별 차감 제한 안내 문구 치환) / 사용한 적립금·예치금 환불 / 네이버 마일리지·OK캐쉬백 환불 / 적립금·예치금 환원액(총 환불액과 동일 배경색)
    • 환불수단·환불계좌·예금주·계좌번호·환불사유는 별도 표로 분리, 위 금액 표와 간격을 두고 배치

    복합과세 주문에서는 반송비와 재발송 배송비에 각각 해당 비용의 환불금 차감 제한 안내 문구를 표시합니다. 적립금·예치금 환원액은 과세·면세 배분 금액만 표시합니다.

  5. 5
    총 환불액 / 실 환불액
    1. 총 환불액환불 예상액 − 전액 과세 배송비 환불액(선택분) − 반송비 − 재발송 배송비 − 사용한 적립금 환불 − 사용한 예치금 환불 − 사용한 네이버 마일리지 환불
    2. 실 환불액총 환불액에서 적립금·예치금 환원액을 제외한 고객의 현금·카드 환불 금액 (운영자가 필요 시 조정)
  6. 6
    환불 처리 · 음수 환불 얼럿
    • "환불 처리" 버튼 클릭(환불 시도) 시점에 계산 결과를 검증
    얼럿 노출 조건 :
    1. 계산 결과(총 환불액 · 실 환불액)가 음수인 경우 → 화면 중앙에 경고 얼럿 노출, 팝업은 현재 상태 유지
    1. 자동 처리 중단금액이 음수인 경우 자동 처리를 실행하지 않음
    2. 후속 처리관리자가 얼럿의 "확인" 클릭 후 원인을 직접 확인·수기 처리
    사용법 : 실제 계산 결과가 음수이면 "환불 처리" 버튼 클릭 시 얼럿을 노출하고 자동 처리를 중단한다. 정책서 6.2절
  7. 7
    환불·배송비 예시 전환 탭
    • 과세 취소 배송비 차감 / 면세 단독 배송비 차감 불가 / 적립금·예치금 환원 있음 예시를 탭으로 전환
    1. 적립금·예치금 환원 있음총 환불액 64,000원 중 적립금 환원액은 과세 1,100원 / 면세 900원, 예치금 환원액은 과세 500원 / 면세 500원으로 표시한다.
    2. 과세 취소 · 배송비 차감과세 상품 환불 예상액 38,000원에서 전액 과세 배송비 3,000원을 차감해 총·실 환불액 35,000원을 표시한다.
    3. 면세 단독 · 배송비 차감 불가면세 상품 환불 예상액 19,000원을 표시하고, 과세 취소금액이 없으므로 배송비 환불액은 0원·선택 불가로 표시한다.
    4. 실 환불액총 환불액에서 적립금·예치금 환원액을 제외한 현금·카드 환불 금액을 표시한다.

    주문 시 사용한 적립금·예치금 환불은 별도 항목이며, 이 예시에서는 0원으로 유지한다.
