화면 설명

  1. 1
    부분성공 상태 배너 노출 조건 :
    1. PG 카드 취소는 성공했으나 내부(적립금·예치금) 처리가 미완료인 경우

    성공한 카드 취소는 중복 실행하지 않는다는 원칙을 함께 안내합니다.

    정책서 6.2절
  2. 2
    PG 취소 결과
    1. 승인번호 / 취소 거래IDPG사 응답값을 그대로 표시 (수정 불가)
    2. PG 취소 금액실제 카드 승인금액 중 PG에 취소 요청한 금액
    정책서 5장
  3. 3
    내부 처리 현황

    적립금·적립성 예치금·현금성 예치금 복원 항목을 각각 완료/미완료 배지로 표시합니다. 미완료 항목만 아래 4번 영역에서 수기 반영 대상이 됩니다.

    정책서 5장
  4. 4
    내부 미완료 건 수기 반영
    • 미완료 항목의 처리자·메모를 입력하고 "수기 반영 처리" 버튼으로 확정
    금액 제한 조건 :
    1. 반영 금액은 스냅샷 기준 잔여 환불 가능액을 초과할 수 없음
    • 4-1
      수기 반영 처리 (버튼)
      • 클릭 시 내부 복원 합계가 갱신되고 아래 대사 결과가 재계산됨
      사용법 : 메모 입력 후 클릭 → 버튼이 "수기 반영 완료"로 바뀌며 비활성화
    정책서 6.2절
  5. 5
    PG 취소 데이터 직접 대조

    PG 취소 금액 합계와 내부 복원 합계(수기 반영分 포함)를 상품 반환 내역 합계(스냅샷 기준)와 비교합니다.

    일치/불일치 표시 조건 :
    1. 세 금액이 모두 같으면 "일치"(녹색)
    2. 하나라도 다르면 "불일치"(빨간색)로 표시하고 완료 처리를 차단
    정책서 5장 · 6.2절
  6. 6
    확인 대상 유지 / 클레임 완료 처리 완료 처리 버튼 활성화 조건 :
    1. 대사 결과가 "일치"인 경우에만 활성화
    2. 불일치 상태에서는 "확인 대상으로 유지"만 가능

    세부 수기 처리 담당·기한, PG 응답·조회 기준, 대사 필드는 PG사와 운영·개발·정산이 확인한 뒤 별도 절차로 확정합니다. [6.3절 후속 검토]
