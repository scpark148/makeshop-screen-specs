    환불금액 정보
    • 라벨 : 환불 예상액 / 최초배송비 환불액 / 총 환불액
    1. 부분 취소·반품최초배송비 1,000원은 표시하고, 설정 ON에서는 자동 차감한다.
    2. 마지막 상품 취소·반품최초배송비 1,000원은 표시하고, 설정 ON에서는 차감하지 않는다.
    [사양정의서 3.2에서 확인]
  3. 3
    최초배송비 환불액 체크박스
    • 라벨 : 차감 체크박스 / 최초배송비 환불액 / 총 환불액
    1. 금액 표시최초배송비는 항상 주문 당시 실제 결제 금액(예시 1,000원)을 표시한다.
    2. 설정 OFF기존 방식으로 체크박스를 선택 또는 해제할 수 있으며, 체크 시 총 환불액과 실 환불액에서 1,000원을 차감한다.
    3. 설정 ON + 부분 처리체크박스를 선택·비활성화하여 최초배송비를 자동 차감한다.
    4. 설정 ON + 마지막 상품 처리체크박스를 해제·비활성화하여 최초배송비를 차감하지 않는다.
    5. 재처리이미 최초배송비를 환불한 경우의 체크 상태와 차감 기준은 확인이 필요하다.

    1. 실제 금액 항목명과 산정·표시 시점은 구현 전 확인한다.

    환불 처리
    • 라벨 : 취소 / 환불 처리
    1. 환불 처리체크박스에 반영된 최초배송비 차감 결과를 포함해 기존 환불 처리 흐름을 실행한다.
    2. 판정 시점마지막 상품 판정 시점은 승인·확정 단계 제안이며 확정이 필요하다.

QA 확인

  • 설정 ON 및 부분 상품 처리 시 최초배송비 1,000원이 표시되고 체크 상태가 비활성화되는지 확인한다.
  • 설정 ON 및 마지막 상품 처리 시 최초배송비 1,000원이 표시되고 체크 해제 상태가 비활성화되는지 확인한다.
  • 체크 상태에 따라 총 환불액과 실 환불액에서 1,000원이 차감되는지 확인한다.
  • OFF일 때는 체크박스를 조작할 수 있는지 확인한다.
