# Makeshop Screen Specs

Makeshop 회사업무의 화면정의서만 공유하는 공개 저장소입니다. [전체 화면정의서 목록 열기](https://scpark148.github.io/makeshop-screen-specs/)

- 화면정의서 HTML과 화면 표시용 CSS·이미지만 포함합니다.
- PRD, 정책서, TC, 회의록, 리서치, 업무 원본은 포함하지 않습니다.
- 아래 링크를 선택하면 각 화면정의서를 바로 열 수 있습니다.
