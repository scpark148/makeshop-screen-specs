화면 설명

  1. 1
    결제수단 선택
    • 결제수단 : 무통장 / 신용카드 / 실시간 계좌이체(에스크로) / 가상계좌(에스크로)
    1. 실시간 계좌이체(에스크로)PG·MID 설정에 에스크로 인증유형이 있는 경우 선택 가능한 결제수단이다.
    2. 가상계좌(에스크로)에스크로 설정이 적용된 경우 선택 가능한 결제수단이다.
    노출 조건 :
    1. 에스크로 대상 수단을 선택하면 인증정보 섹션을 노출한다.
    2. 일반 결제수단을 선택하면 인증정보 섹션을 노출하지 않는다.
    정책서 3.1
  2. 2
    인증정보 입력
    • 라벨 : 인증유형 / 인증값 / 필수 표시
    1. 인증유형PG 허용값만 표시한다. 둘 다 허용하면 휴대폰번호를 기본 선택한다.
    2. 인증값구매자가 해당 거래를 위해 직접 입력한다. 주문자 연락처를 자동 대체하지 않는다.
    주문 차단 조건 :
    1. 인증값이 비어 있거나 선택한 유형의 형식과 다르면 결제를 요청할 수 없다.
    2. 인증정보 설정이 없는 일반 결제수단에는 이 섹션을 노출하지 않는다.
    정책서 3.1~3.2
    • 2-1
      인증유형 선택 (셀렉트)
      • 휴대폰번호 또는 인증번호 6자리를 선택한다.
      사용법 : 유형 선택 → 입력 안내문구와 최대 입력 길이가 변경된다.
      1. 휴대폰번호숫자 형식의 휴대폰번호를 입력한다.
      2. 인증번호 6자리숫자 6자리를 입력한다.
  3. 3
    에스크로 안내 및 입력 오류
    • 안내 : 사용 목적 / 주문 불가 조건
    1. 처리 목적 안내구매확인·구매거절 등 에스크로 상태변경 처리에 사용됨을 노출한다.
    2. 입력 오류필수값 미입력 또는 형식 불일치 시 해당 입력 영역에 오류 문구를 노출한다.
    보안 유의 :
    1. 인증값 원문은 주문상세·관리자 화면·로그에 표시하지 않는다.
    정책서 3.3, 6장
