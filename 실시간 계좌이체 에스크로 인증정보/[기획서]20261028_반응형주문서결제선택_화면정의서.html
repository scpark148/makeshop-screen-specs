화면 설명

  1. 1
    PC 결제수단 선택
    • 결제수단 : 페이팔 / 무통장 / 신용카드 / 실시간 계좌이체 / 토스페이 / 에스크로 결제수단
    1. 배치PC 주문서 폭에서 4열 버튼 그리드로 노출한다. 두 번째 행에는 남은 일반 수단과 에스크로 수단을 같은 버튼 규격으로 배치한다.
    2. 선택 상태선택한 결제수단 버튼은 검정 테두리로 표시한다.
    노출 조건 :
    1. 실시간 계좌이체(에스크로) 또는 가상계좌(에스크로)를 선택한 경우에만 인증정보 영역을 노출한다.
    2. 일반 실시간 계좌이체·카드·간편결제 등 비대상 수단에는 인증정보 영역을 노출하지 않는다.
    정책서 3.1
    • 1-1
      무통장 세부 입력 (조건부)
      • 라벨 : 입금자명 / 계좌
      사용법 : 무통장 선택 시에만 결제수단 하단에 노출한다.
      1. 입금자명·계좌무통장 전용 입력 항목이다.
      차단 조건 :
      1. 실시간 계좌이체(에스크로)·가상계좌(에스크로) 선택 상태에서는 해당 영역을 표시하지 않는다.
  2. 2
    PC 에스크로 인증정보
    • 라벨 : 인증유형 / 인증값 / 필수 표시
    1. 인증유형PG·MID 설정에서 허용한 값만 표시한다. 두 유형을 모두 허용한 경우 휴대폰번호를 기본값으로 선택한다.
    2. 인증값구매자가 해당 거래를 위해 직접 숫자로 입력한다. 주문자 연락처를 자동 대체하지 않는다.
    주문 차단 조건 :
    1. 인증값이 비어 있거나 선택한 유형의 형식과 다르면 주문할 수 없다.
    정책서 3.2~3.3
  3. 3
    모바일 결제수단 선택
    • 구성 : 주문서 헤더 / 결제 선택 제목 / 2열 결제수단 버튼
    1. 배치모바일 주문서 폭에서 결제수단을 2열 버튼 그리드로 노출한다. 일반 결제수단과 에스크로 결제수단은 동일한 선택 방식으로 제공한다.
    2. 상단 구조이전 버튼·주문서 제목·홈 아이콘을 포함한 모바일 주문서 헤더를 사용한다.
    노출 조건 :
    1. 무통장 세부 입력은 무통장 선택 시에만 노출한다.
    2. 에스크로 결제수단 선택 시 모바일 인증정보 영역으로 전환한다.
    정책서 3.1
  4. 4
    모바일 에스크로 인증정보
    • 라벨 : 인증유형 / 인증값 / 필수 표시 / 안내문구
    1. 입력 배치모바일에서는 인증유형 셀렉트와 인증값 입력 필드를 세로로 노출한다.
    2. 안내문구구매확인·구매거절 처리 목적과 거래 완료 후 파기 기준을 인증값 하단에 노출한다.
    주문 차단 조건 :
    1. 입력값 검증 실패 시 주문 요청을 차단하고 해당 필드에 오류를 노출한다.
    2. 에스크로가 아닌 결제수단으로 변경 시 인증정보 영역을 즉시 숨긴다.
    정책서 3.2~3.3
